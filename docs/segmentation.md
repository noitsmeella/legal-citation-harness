# 문장 분할 규칙

`src/harness/segment.py`가 구현하는 규칙이다. 규칙을 바꾸면 코드, 테스트(`tests/test_segment.py`), 이 문서를 함께 고친다.

1. 줄바꿈은 항상 문장 경계다. 빈 줄은 버리고 각 문장의 앞뒤 공백을 지운다.
2. 마침표·물음표·느낌표 뒤에 공백이 오면 나눈다.
3. 괄호 안에서는 나누지 않는다. (판례 인용 "(대법원 2010. 1. 14. 선고 … 참조)" 보호)
4. 한국어: 마침표 바로 앞이 숫자면 나누지 않는다. (날짜 "2020. 3. 5.", 번호 "1.")
5. 영어: 마침표로 끝나는 단어가 약어 목록(`US_ABBREVIATIONS`)에 있으면 나누지 않는다.

## 알려진 한계

- 한국어 긴 문장의 절 단위 분할은 자동으로 하지 않고 주석 단계에서 손으로 한다.
- 영어 문장이 약어로 끝나는 경우("… in the U.S. The court…")는 잘못 붙는다. 발견하면 손으로 고치고 아래에 기록한다.
